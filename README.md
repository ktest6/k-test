
## 디렉토리 구조

```
K-TEST/
├── frontend/     # Next.js — 한효주
├── backend/      # NestJS — 백예나
├── assessment/   # 문항 개발 + AI 채점 (Python) — 전재완
└── anti-cheat/   # 부정행위 탐지 (Python) — 김도영
```

- 각자 자신의 디렉토리 안에서 작업합니다.
- **자기 디렉토리 밖에 새로운 디렉토리가 필요하거나 다른 방식이 필요하면, 자유롭게 새 디렉토리를 만들어** 진행하세요.
- 단, 새로 만든 디렉토리는 **무엇을 위한 곳인지 README.md를 작성**하고, 처음 보는 사람도 이해할 수 있도록 이름을 짓습니다.

## 브랜치 규칙

- `main` 브랜치에 **직접 push 금지**
- 모든 작업은 **기능 브랜치**에서 진행하고 **PR(Pull Request)로 머지**
- 머지 전에는 **최신 `main`을 받아 자신의 브랜치에 반영**하고, **직접 실행해 정상 동작을 확인**할 것
- 확인이 끝나 **문제없다고 판단되면 스스로 머지**
- **다른 팀원의 디렉토리를 수정해야 할 경우, 머지 전에 반드시 해당 팀원에게 미리 알리고 합의해주세요**
- 브랜치는 **작업 단위(기능·수정 하나)로 생성**하고, **머지가 끝나면 바로 삭제**해 브랜치 목록을 깔끔하게 유지
