# LoRA 데이터 보강 설계 — 데이터를 "만들기" 전에, 순서가 있다 (2026-08-19)

> 쉬운 요약: LoRA 학습 데이터가 부족하다는 문제를 4갈래로 풀 수 있다.
> **① 공짜 실험 2개(GPU 0) → ② 실데이터 3,500시간 추가 확보(자동승인) → ③ 학습 목표·라벨 교정 → ④ 합성 데이터(TTS)** 순서다.
> 합성이 제일 화려해 보이지만, 조사 결과 근거가 가장 강한 것은 ②·③이고 합성은 조건부 4순위다.

## 이 문서가 나온 과정

조사 에이전트 14개(주제 조사 7 + 적대 검증 7)를 병렬로 돌려 논문·도구·데이터셋 69건을 모았고,
검증자가 **모든 출처의 원문(arXiv 본문·GitHub 코드·AI Hub 페이지)을 실제로 열람**해 대조했다.
결과: 지어낸 인용 0건, 수치 정정 6건(그중 하나는 Common Voice 규모 36배 과대 — 폐기).
아래에 남긴 것은 검증을 통과한 것뿐이다. `CONFIRMED` = 원문에서 수치까지 확인, `PLAUSIBLE` = 실재하나 세부 수치 미확인.

## 0. 전제 — 우리 실측이 말하는 것 (여기서 출발해야 한다)

- v1은 밑바탕 Whisper-small과 통계적으로 구분되지 않았다(4지표 모두 신뢰구간이 0을 걸침).
- **병목은 "양"이 아니었다** — 낭독 쌍의 56.5%에 오류가 들어 있어 신호는 충분했는데, "사람 전사에 가깝게"(CER 최소화) 학습으로는 정직함이 안 올라갔다(8/9 실측).
- 라벨의 약 33%가 세탁 노이즈였고, 자유발화(3,651쌍)는 낭독(6,500쌍)에 밀려 실제로 얇다(CER 27.1% vs 9.9%).
- 그래서 "데이터를 무한정 합성해 붓는다"는 답이 아니다. **오류 신호가 라벨에 100% 살아 있는 데이터**를 늘리고, **그 신호를 학습 목표가 실제로 겨냥하게** 만드는 것이 답이다.

이 진단은 독립 연구로도 교차 확인됐다:
- 라벨 표기 충실도만 고쳐도 verbatim(들린 대로) 전사 WER이 상대 11.3% 개선 — Whisper LoRA + L2 학습자, 우리와 같은 세팅 (arXiv:2506.04076, CONFIRMED)
- 라벨 노이즈는 완화 트릭으로 못 메우고 라벨 품질 확보가 우선 (arXiv:2112.00350, CONFIRMED)
- 전사 스타일(들린 대로 vs 고쳐 적기)은 학습 데이터의 통제 안 된 변수이며, 이 불일치가 보고 WER의 최대 60%를 차지 (arXiv:2607.18934, CONFIRMED)

## A. 공짜 실험 2건 (P0 — GPU 0, 오늘 반나절)

**A-1. 낭독 지문을 디코더 프롬프트로 주입.** Whisper는 디코더에 힌트 문장(prompt)을 넣을 수 있다.
낭독 문항은 제시문을 아니까, 제시문을 프롬프트로 주고 골든셋 낭독 갈래에서 오류보존율·오탐율만 잰다.
근거: 프롬프팅이 파인튜닝보다 verbatim 전사에 유리했다는 Apple 연구 (arXiv:2505.23627, Interspeech 2025 게재, CONFIRMED).
효과가 있으면 **학습 없이** 채점 파이프라인에 반영 가능.

**A-2. 71479 원본의 미사용 파트 인벤토리.** 원본 전체는 1,500시간인데 우리는 10,151쌍만 꺼내 썼다.
이 시리즈에는 **"발음오류가 그대로 드러나는 수동 발음전사" 필드와 발음숙련도·유창성·이해가능도(1~5점) 평가점수**가 들어 있다(AI Hub 페이지에서 확인, CONFIRMED).
발음전사 ↔ 철자전사가 어긋나는 자리 = **사람이 이미 표시해 둔 "진짜 오류 위치"**다. 세탁 탐지기 없이도 오류 자리를 아는 감독 신호가 공짜로 생긴다.

## B. 실데이터 확장 (P1 — 가장 타당성 높은 "데이터 부족" 해법)

같은 '교육용' 시리즈가 3종 더 있고, 전부 페이지에서 규모·라벨 구성을 확인했다(CONFIRMED):

| 데이터셋 | 번호 | 규모 | 우리에게 주는 것 |
|---|---|---|---|
| 교육용 영어권 | 71469 | 1,029.8h | 같은 스키마 — 전처리 코드 재사용 |
| 교육용 유럽어권 | 71489 | 1,538.5h | v2가 본 적 없는 언어권 홀드아웃 평가셋 |
| 교육용 중·일어권 | 71490 | 1,006.2h | 국내 외국인 노동자 분포에 가장 가까운 L1 |
| 외국인 발화(2021) | 505 | 4,302h | 규모 최대. 단 오류 보존 여부 미명시 — 게이트 필요 |

- 3종 모두 **수동 발음전사(오류 보존) + 1~5점 평가점수 라벨 포함.** 평가점수는 2단계 XGBoost(계단 5)의 지도 라벨로 그대로 투입 — 사람 라벨링 없이 수천 건.
- 절차: 내국인 계정 신청(우리 71479 승인 계정 그대로), aihubshell로 자유발화 파트+라벨 JSON만 선별 수신(전송·디스크가 실질 병목).
- **505 게이트**: 샘플 100~200건만 먼저 받아 세탁 탐지기로 세탁률 실측 → 기존 원천의 33%와 비교해 투입 결정.
- 보조: 국립국어원 학습자 말뭉치(총 1,588만 어절, 오류 주석 포함)는 **음성 원본을 제공하지 않는다**(소개 페이지 명시) — STT 학습엔 못 쓰고, 오류 주석 텍스트를 errors.py 검증 골드와 오류 분포표로 쓴다. 신청은 오늘(승인 지연 대비).
- 탈락 확인: Common Voice 한국어는 검증 2.54시간뿐(조사 초안의 375시간은 36배 과대로 판명, 폐기). 유튜브 크롤링 학습은 약관·저작권 회색지대 — 본선 일정 내 비권장.

## C. 학습 목표·라벨 교정 (P1 — 병목 실측에 정면 대응)

### C-1. verbatim 스타일 태그 — 세탁 의심 11%를 버리지 않고 되살린다

디코더 앞에 `<verbatim>`(들린 대로) / `<cleaned>`(고쳐 적음) 태그 토큰을 붙여 학습하고, 추론 때 `<verbatim>`을 강제한다.
- 근거: 모델 전체를 얼리고 **태그 임베딩 27개만 1 에폭** 학습해도 비유창성 F1 10%→79%, 디코더까지 풀면 90.7% (CrisperWhisper 팀, arXiv:2607.18934, CONFIRMED). 이 논문의 verbatim 데이터는 약 362시간 — 우리 규모와 격차가 생각보다 작다.
- 우리식: 세탁 탐지기 판정으로 keep=`<verbatim>`, suspect=`<cleaned>` 태그를 달면 **v2에서 걷어낸 1,116쌍이 삭제 대신 학습 재료로 복귀**한다. "세탁 라벨도 정보다(어느 쪽 스타일인지 알려주는)"로 관점이 바뀐다.

### C-2. 재라벨 공장 — 증인 4명을 탐지기에서 교정기로 뒤집기

증인 앙상블(qwen3-asr·fw-small·owsm-v4·sensevoice)의 **합의 전사를 새 라벨로 채택**한다.
- 근거: 여러 ASR의 쌍별 일치도가 높은 구간만 골라 학습하면 7,500시간을 100시간으로 줄이고도 전체 학습과 동급(12.2% vs 12.3% WER) (arXiv:2506.03681, Interspeech 2025, CONFIRMED). 정답 라벨 없이 필터가 성립 (uDistil-Whisper, NAACL 2025, CONFIRMED). 의사라벨은 WER 10% 문턱 필터가 균형점 (Distil-Whisper 본문 Table 10, CONFIRMED).
- 이중 조건으로만 교체: **앙상블 합의(쌍별 CER ≤ 5%) AND 합의-사람라벨 WER > 10%.** 탐지기 단독 정밀도(48.6%)로 바꾸면 절반은 멀쩡한 라벨을 훼손한다.
- 동률·근소 불일치는 Gemini에 **"4개 전사 중 선택만"**(생성 금지 — 세탁 재유입 차단) 시킨다 (arXiv:2506.11089 방식, CONFIRMED).
- **필수 게이트(학습 전)**: 골든셋 499건에서 "합의 전사의 오류보존율"이 원 라벨보다 높은지 먼저 잰다. 낮으면 증인들도 세탁 중이라는 뜻 — 이 갈래를 중단한다. (증인 자신의 보존율 67~79%가 천장이라는 8/8 실측과 일관된 안전장치.)
- 학습 순서는 WSP: 재라벨 대량셋으로 먼저, 팀원 귀검수 고품질 소량셋(300~500건)으로 마무리 (arXiv:2505.17088, CONFIRMED). 라벨에서 단어가 통째로 빠진 "삭제 방향" 불일치를 최우선 제거 (arXiv:2112.00350).
- 한국어 선행: 같은 구조(비원어민 한국어 + G2P 발음 타깃 + 교차모델 합의 다단계 정제)가 Applied Sciences 2026에 게재됨 (MDPI 16(5):2426, PLAUSIBLE — 본문 403, 수치 인용은 PDF 확보 후). 같은 그룹 선행(eksss 2025)은 AI Hub 교육용 데이터로 비원어민 PER 12.50%→3.22% (CONFIRMED).

### C-3. 손실·구조 조정 (코드 몇 십 줄)

- **토큰 가중 CE**: 사람 전사 vs 표준어 정규화본의 diff로 오류 토큰 위치를 찾아 가중 2~3배, 세탁 의심 쌍은 0.3~0.5배(소프트 — 탐지기 오탐 방어). 근거: 라벨 신뢰도를 토큰 단위로 손실에 반영해 최대 38% 개선 (arXiv:2406.18108, RNN-T 기준, CONFIRMED — seq2seq 이식은 우리가 검증할 몫).
- **LoRA 타깃 확장**: q,v만으로는 full FT 성능이 안 나온다는 것이 QLoRA의 명시 결론 — 전 선형층(q,k,v,o,fc1,fc2)으로 확장, r=8~16 (arXiv:2305.14314, CONFIRMED). 단 **α/r은 낮춰서(0.2~1) ablation** — Whisper에서 α=2r이 디코더를 과수정해 환각을 유발한다는 반대 근거가 있다 (arXiv:2606.07608, 단독 저자 프리프린트이므로 참고 수준).
- **낭독:자유발화 균형 샘플러** (자유발화 오버샘플링).
- 참고: Whisper는 클수록 비표준 억양에서 표준형 끌림·반복 폭주가 심해진다는 벤치마크 (arXiv:2604.21276, CONFIRMED) — small 유지의 방어 논리.

### C-4. (여력 시) DPO — "세탁한 전사를 지는 답으로" 가르치기

DPO(선호최적화): 같은 입력에 좋은 답(chosen)과 나쁜 답(rejected)을 짝지어 "이쪽을 선호하라"고 가르치는 방법.
- chosen = 오류 보존 전사, rejected = 세탁본. **자연쌍이 이미 있다**: 교정라벨.jsonl 164건(label_orig=세탁, gold=보존) + 세탁 탐지기가 찾은 자리 1,270곳. 대량은 Gemini로 사람 전사를 "세탁"시켜 생성(전체 세탁 80% + 부분 20%).
- 근거: 코드스위칭 ASR에서 "번역(정규화)된 전사를 rejected로" 놓은 DPO 1 에폭이 MER 70.98%→7.38% (arXiv:2605.23975, CONFIRMED); OWSM 기반 BPO가 SFT 대비 상대 11.4% (arXiv:2412.19005, AAAI 2025, CONFIRMED).
- 주의: encoder-decoder Whisper용 DPO는 직접 구현(~150줄)이고 whisper-small에서의 안정성은 선행이 없다 — 실패해도 C-1~C-3만으로 제출 가능한 구조로 쌓는다.

### C-5. v3 학습 구조 — 3단으로 쌓는다 (8/19 확정안, 그림: `v3_학습설계도_20260819.html` · https://claude.ai/code/artifact/2b28624e-7875-40fa-9de2-381d412d812a)

밑바탕 Whisper-small은 얼리고 LoRA 판(전 선형층)만 배운다. 한 번에 다 붓지 않고 **같은 LoRA 판을 3단으로 이어서** 가르친다. 추론 때는 `<verbatim>` 꼬리표를 강제.

| 단 | 재료 | 방식 | 에폭 | 통과 기준 |
|---|---|---|---|---|
| 1 대량 | 정제 9,035 + 증인 합의 재라벨 복구분 (+합성 ≤30%, 게이트 시) | 꼬리표 · 오류 토큰 가중 2~3배 · 세탁 의심 0.3~0.5배 · 낭독:자유발화 균형 | 2~3 | 오류보존율 CI가 base와 분리 |
| **2 고품질 마무리** | **팀원 교정본 중 학습용 1,000** (전부 `<verbatim>`) | 같은 손실, 데이터만 교체, 낮은 학습률(1단의 1/3~1/5) | 1 | 보존율↑ & 오탐율 유지 → **v3 기본형** |
| 3 선호(선택) | 선호쌍: 학습용 1,000 중 고쳐진 건(원본 세탁본 vs 교정본, ~330쌍) + Gemini 세탁본 | DPO β≈0.1, 2단 모델을 기준(frozen)으로 LoRA만 갱신 | 1 | 2단 대비 보존율↑, CER 악화 CI 내. 불안정하면 2단으로 제출 |
| 평가 | **시험지: 교정본 1,500(개발 750/실전 750) + 골든 499** | base·v1·v2·v3 같은 파일·부트스트랩 2,000회 | — | 오류보존율·오탐율·CER(중앙값 병행) |

- 2,500 교정본의 시험지/학습용 분리는 **결과를 보기 전에 파일 이름으로** 한다(gold와 같은 원칙). 시험지는 어느 단에도 넣지 않는다.
- "소량 고품질을 1단에 섞지 않고 2단에 따로 두는 이유": 9,035건 속에 섞이면 희석되지만 마지막에 따로 보여주면 모델이 가장 최근에 본 것이 되어 영향이 가장 크다(WSP, arXiv:2505.17088).
- 시험지/학습용 비율(1,500/1,000)과 합성 투입 여부는 8/20 평가 기준 회의에서 최종 확정.

## D. 합성 데이터 — 오류 주입 텍스트 → TTS (P2, 게이트 통과 시에만)

**구조**: 오류가 적힌 텍스트를 TTS가 "적힌 대로" 읽으면 (오류 음성, 오류 전사) 쌍이 자동 생성 — 라벨-음성 일치 100%.
한글은 표음문자라 '개료'·'있슴다'가 쓴 대로 읽히기 쉽다. 같은 구조(T2S)로 발음오류 탐지 AUC 0.528→0.749를 만든 선례가 있다 (Amazon Korzekwa, arXiv:2207.00774·2209.06265, CONFIRMED).

### D-1. 오류 텍스트 생성 — 규칙 우선, LLM 보조

- **규칙/G2P 경로 우선**: 무작위·규칙 음소 치환만으로 LLM 정교 편집 이득의 대부분이 회수된다는 실측 (arXiv:2604.27273, CONFIRMED — 단 한국인 억양 "영어" 실험). 규칙표 출처: 우리 데이터와 같은 AI Hub 코퍼스에서 5개 L1의 오류 패턴 39종을 정리한 ICPhS 2023 (arXiv:2306.10821, CONFIRMED — 격음·경음→평음, 종성 탈락, 이중모음 단모음화, 베트남어 /l/→/n/), 베트남어 화자 종성 /ㄹ/ 오류율 실측(초급 81%·중급 68.2%·고급 27.6%, KCI, 급수별 주입 확률로 사용).
- **LLM 경로 보조**: "무작위로 틀리게"가 아니라 **오류 유형 태그 + 실측 분포 + 실제 예시** 3종 세트로 조건화 (Stahlberg & Kumar tagged corruption, BEA 2021, CONFIRMED; 아랍어 채점용 GPT-4o 오류 주입, BEA 2025, CONFIRMED; LLM 역방향 오류 생성이 비영어 3개 언어에서 유효, EMNLP 2024 Findings, CONFIRMED). 분포표는 KAGAS(한국어 14유형 자동 주석, ACL 2023)로 골든셋에서 자동 산출, 태그 체계는 K-NCT(4대분류·23하위)를 빌린다.
- 자유발화체에서도 뽑을 것(낭독 쏠림 악화 방지). 오류 없는 문장도 30% 섞기(오탐율 방어).

### D-2. TTS 도구 — 코드까지 확인된 순위

| 순위 | 도구 | 라이선스 | 판정 근거 |
|---|---|---|---|
| 1 | CosyVoice2-0.5B | Apache-2.0 | 한국어 zero-shot 복제 지원. **frontend.py에 한글 철자를 교정하는 경로가 없음을 코드로 확인**(단, 숫자는 영어로 풀릴 위험 — 스모크에 숫자 문장 포함) |
| 2 | GPT-SoVITS v2 | MIT | 한국어 프런트엔드가 g2pk2 표면형 발음규칙만 적용(korean.py 확인). 화자별 1분 파인튜닝 지원 — 억양이 필요하면 이쪽 |
| 보험 | ElevenLabs API | 상용 | `apply_text_normalization=off` 파라미터 존재. 약 $40/40만자. **합성물로 타사 모델 학습이 약관상 되는지 확인 후** |
| 배제 | XTTS-v2 | CPML | 비상업 + Coqui 폐업으로 상용 라이선스 구매 불가 |
| 배제 | Fish-Speech/OpenAudio | 자체 | 라이선스가 "자료를 다른 AI 모델 학습에 사용" 자체를 금지 — 우리 용도와 정면 충돌 |

- 화자 프롬프트는 AI Hub 실제 L2 화자 50~200명의 3~10초 클립을 순환 사용(화자 다양성 + L2 음색).
- **스모크 게이트(D 전체의 선행 조건)**: 오류 문장 30~50개('개료'·'있슴다'·'됀다'·숫자 포함)를 합성 → 증인 ASR 재전사로 "적힌 대로 소리 났는가" 판정. **합격률 80% 미만이면 도구 폐기, 대안도 실패하면 D 갈래 전체 중단.** (LLM 기반 TTS가 오류를 표준음으로 교정해 읽으면, 우리가 싸워 온 세탁을 거꾸로 학습시키는 독이 된다.)

### D-3. 혼합·검증 규칙

- 대량 합성 후 **증인 앙상블 거부 샘플링**: 증인 과반이 의도한 오류 어형을 받아 적은 클립만 통과 (SYNT++ — 필터 없는 나이브 혼합은 손해, CONFIRMED).
- 통과분에 속도 0.9/1.0/1.1 + 60% 확률 노이즈 + 잔향(Meta Interspeech 2023 레시피, CONFIRMED) — 합성 음향 과적합 방지.
- **혼합 비율 10%에서 시작, 30% 상한 ablation** (Meta 실측: 특정 도메인 데이터엔 10% 이하가 최적). 합성 단독 학습 금지(합성 단독 33.8% vs 실발화 14.1%의 반례 실측 있음).
- 학습 순서는 "합성으로 먼저 → 실쌍으로 마무리" 2단계 (Kiyono EMNLP 2019: PRETRAIN > JOINT, CONFIRMED).
- **평가는 골든셋 실음성 499건으로만.** 합성음 평가셋 금지.

## 함정 목록 (전 갈래 공통)

1. **TTS 세탁**: 스모크 게이트 없이 합성하면 (오류 라벨, 교정 음성) 쌍 = 반대 신호를 주입하게 된다.
2. **증인 만장일치 세탁**: 증인 4종 모두 표준어 코퍼스 출신이라 '개료'를 똑같이 '재료'로 적으면 합의 필터가 세탁을 정답으로 승격시킨다 → C-2 게이트 필수.
3. **합성 음향 과적합**: "TTS 음색이면 적힌 대로, 실음성이면 표준어로"를 배울 수 있다 → 혼합 상한 + 실음성 평가.
4. **비교 공정성**: v1/v2와 비교는 반드시 같은 골든셋 499 + 같은 부트스트랩 CI. 학습셋 구성이 바뀌므로 이것만이 공통 자다.
5. **기대치 관리**: 인용 수치는 대부분 영어·타 과제의 것 — "오류보존율" 그 자체를 겨냥한 선행은 없다(이건 우리 차별점이기도 하다). 개선 폭은 낙관적 상한으로 읽는다.
