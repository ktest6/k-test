# 논문화 후보 방법론 — 선행 연구 대조 후 정제본

> 8/2 작성. 원칙: 심사장·논문 어디서든 "이미 있는 걸 새롭다고 말하다 무너지는" 사고를 막기 위해,
> 후보마다 **선행 연구가 이미 가져간 것**과 **아직 우리 것**을 구분해 둔다.
> 주장은 항상 측정 범위와 함께 (광의 SOTA 주장 금지 — PLAN.md 궁극 목표 절 참고).

## 후보 1. 받아쓰기 세탁(error-erasure) 편향 — ★ 각도를 좁히면 산다

**선행이 가져간 것**: ASR 오류가 L2 숙련도 측정치를 훼손한다는 것 자체는 알려져 있다
(ASR 전사로 재면 문법 복잡도 지표와 사람 점수의 상관이 떨어진다는 실측,
arXiv:2104.08529). ASR+문법교정(GEC)으로 말하기 채점하는 흐름도 있다.

**아직 우리 것 (정제된 연구 질문)**: 선행은 ASR 오류를 대체로 "무작위 잡음"으로 다룬다.
우리 질문은 방향이 있다 — **ASR 정규화는 학습자를 실제보다 잘하게 보이게 만드는
한쪽 방향 편향**(오류 지우개)이라는 것. 실측 근거 확보됨: "안 돼습니다"→"안 됐습니다",
"삼번"→"3번" (few-shot 지시로도 못 막음, 소리 동일). 한국어 L2에서 이 편향을
오류 유형별(조사/어미/발음성 표기)로 정량화한 연구는 검색 범위에서 없음.

**실험 설계**: AI Hub 교육용 세트(오류 보존 사람 전사 포함) N≥100 발화.
조건 A: 사람 전사(오류 보존)로 채점 / 조건 B: Gemini 전사로 채점 / (Azure 오면 C 추가).
측정: 언어 사용 점수 차이(B−A)의 부호와 크기, 오류 유형별 소실률.
가설: B−A > 0 (세탁 방향), 소리로 구별 안 되는 유형(돼/됐)에서 소실률 최대.
위협: TTS가 아닌 실발화 필요(확보 예정), 사람 전사 품질에 의존.

## 후보 2. 채점 파이프라인의 환각 점수 인플레이션 공격 — ★ 프레임 전환 필수

**선행이 가져간 것**: 무음·비발화 구간에서 STT가 환각한다는 것(Careless Whisper,
FAccT 2024), VAD(음성 구간 탐지) 전처리가 환각을 줄인다는 것(SileroVAD 계열),
무음이 길수록 환각이 는다는 정량까지 **전부 선행에 있다.** "무음 환각 발견"을
우리 기여로 말하면 안 된다.

**아직 우리 것 (정제된 연구 질문)**: ① **문항 힌트가 환각을 '그럴듯한 모범답안'으로
유도한다** — 정확도를 올리려고 넣는 문항 맥락이 무음에서는 공격 표면이 된다는 역설.
② 그 환각이 **고부담 점수로 전파**되는 경로의 실측 — 생 LLM은 무음에 95점 A와
채점 근거까지 지어냈고(환각이 근거를 오염), 지시("말 없으면 빈 값") 방어는 실패,
신호 기반 관문(RMS)만 성공. ③ 이를 묶은 **채점 파이프라인용 악성 입력 벤치마크**
(무음/외국어/지시문 낭독/한 마디 + 쓰기 가드 4종 사례).
= "환각 연구"가 아니라 **"평가 시스템의 적대적 강건성"** 논문으로 프레임.

**실험 설계**: 공격 세트 × 시스템 3종(생 LLM 직접 채점 / STT→LLM 채점 /
STT→우리 구조) × 방어 2종(프롬프트 / 신호 관문). 이미 절반 실측됨
(outputs/stair4_speaking_20260802.json). 남은 것: 공격 유형 확장(배경 소음,
음악, 부분 무음), 반복 횟수 늘려 통계화.

## 후보 3. 인용 검증 게이트를 단 문항 자동 생성 (트랙B 재개 시)

선행 대조 미완 — LLM 문항 자동 생성(AIG)은 활발한 분야라 다음 조사에서
"인용 근거 강제 + 자동 폐기 게이트 + 채점 가드 예행(G4)"의 선례 유무 확인 필요.
실측 자산: 폐기율 100%→0%, 관문 5종, 생성-채점 무결 분리 증명.

## 후보 4. 외국인 노동자 직무 한국어 벤치마크 공개 (2단계 후)

문항 세트 + 루브릭 + 이중 라벨 답안 + 악성 공격 세트 + 인간-인간 일치율.
데이터셋 논문은 신규성 부담이 가장 낮고, 이 도메인은 공백. 2단계 라벨링이 완성 조건.
주의: AI Hub 원자료는 재배포 금지라 벤치마크에 포함 불가 — 자체 제작분만.
