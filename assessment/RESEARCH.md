# 논문화 후보 방법론 — 선행 연구 대조 후 정제본

> 8/2 작성. 원칙: 심사장·논문 어디서든 "이미 있는 걸 새롭다고 말하다 무너지는" 사고를 막기 위해,
> 후보마다 **선행 연구가 이미 가져간 것**과 **아직 우리 것**을 구분해 둔다.
> 주장은 항상 측정 범위와 함께 (광의 SOTA 주장 금지 — PLAN.md 궁극 목표 절 참고).

## 후보 1. 받아쓰기 세탁(error-erasure) 편향 — ★ 각도를 좁히면 산다

**선행이 가져간 것**: ASR 오류가 L2 숙련도 측정치를 훼손한다는 것 자체는 알려져 있다
(ASR 전사로 재면 문법 복잡도 지표와 사람 점수의 상관이 떨어진다는 실측,
arXiv:2104.08529). ASR+문법교정(GEC)으로 말하기 채점하는 흐름도 있다.

**아직 우리 것 (정제된 연구 질문)**: 선행은 ASR 오류를 대체로 "무작위 잡음"으로 다룬다.
우리 질문은 방향이 있다 — **ASR 정규화는 학습자를 실제보다 잘하게 보이게 만드는
한쪽 방향 편향**(오류 지우개)이라는 것. 실측 근거 확보됨: "안 돼습니다"→"안 됐습니다",
"삼번"→"3번" (few-shot 지시로도 못 막음, 소리 동일). 한국어 L2에서 이 편향을
오류 유형별(조사/어미/발음성 표기)로 정량화한 연구는 검색 범위에서 없음.

**실험 설계**: AI Hub 교육용 세트(오류 보존 사람 전사 포함) N≥100 발화.
조건 A: 사람 전사(오류 보존)로 채점 / 조건 B: Gemini 전사로 채점 / (Azure 오면 C 추가).
측정: 언어 사용 점수 차이(B−A)의 부호와 크기, 오류 유형별 소실률.
가설: B−A > 0 (세탁 방향), 소리로 구별 안 되는 유형(돼/됐)에서 소실률 최대.
위협: TTS가 아닌 실발화 필요(확보 예정), 사람 전사 품질에 의존.

## 후보 2. 채점 파이프라인의 환각 점수 인플레이션 공격 — ★ 프레임 전환 필수

**선행이 가져간 것**: 무음·비발화 구간에서 STT가 환각한다는 것(Careless Whisper,
FAccT 2024), VAD(음성 구간 탐지) 전처리가 환각을 줄인다는 것(SileroVAD 계열),
무음이 길수록 환각이 는다는 정량까지 **전부 선행에 있다.** "무음 환각 발견"을
우리 기여로 말하면 안 된다.

**아직 우리 것 (정제된 연구 질문)**: ① **문항 힌트가 환각을 '그럴듯한 모범답안'으로
유도한다** — 정확도를 올리려고 넣는 문항 맥락이 무음에서는 공격 표면이 된다는 역설.
② 그 환각이 **고부담 점수로 전파**되는 경로의 실측 — 생 LLM은 무음에 95점 A와
채점 근거까지 지어냈고(환각이 근거를 오염), 지시("말 없으면 빈 값") 방어는 실패,
신호 기반 관문(RMS)만 성공. ③ 이를 묶은 **채점 파이프라인용 악성 입력 벤치마크**
(무음/외국어/지시문 낭독/한 마디 + 쓰기 가드 4종 사례).
= "환각 연구"가 아니라 **"평가 시스템의 적대적 강건성"** 논문으로 프레임.

**실험 설계**: 공격 세트 × 시스템 3종(생 LLM 직접 채점 / STT→LLM 채점 /
STT→우리 구조) × 방어 2종(프롬프트 / 신호 관문). 이미 절반 실측됨
(outputs/stair4_speaking_20260802.json). 남은 것: 공격 유형 확장(배경 소음,
음악, 부분 무음), 반복 횟수 늘려 통계화.

## 후보 3. 인용 검증 게이트를 단 문항 자동 생성 — ★ 조합·시스템 기여로 좁히면 산다 (8/2 대조 완료)

**선행이 가져간 것**: LLM 문항 자동 생성(AIG) 자체와 품질 관리 파이프라인은 활발한
분야다 — LLM을 검수자로 쓰는 QC(답변 가능성·사실 일치·오답지 품질 판정,
Gorgun 2025 EM:IP), 모의 응시자로 난이도 추정, 난이도 제어 다중 에이전트까지 있다.
인용 근거 검증도 RAG·과학문헌 쪽에 잘 발달돼 있다(CiteCheck 등, 상용 모델 인용
환각률 11~57% 보고).

**아직 우리 것**: 선행 QC는 대부분 **LLM이 LLM을 검사**하는 부드러운 게이트다.
우리 것은 ① **결정적(코드) 인용 게이트** — 문서에 그 구절이 물리적으로 있는지
문자열 대조, 없으면 자동 폐기(판단 아닌 검증) ② **채점 가드 예행(G4)** — 생성
문항을 배포 전에 운영 채점기의 유효성 가드에 미리 통과시키는 생성-채점 통합
검사(선례 검색에서 못 찾음) ③ 실무 실측(폐기율 100%→0%, 프롬프트 규칙의 효과
분리). = "AIG 신개념"이 아니라 **"고부담 시험용 AIG의 결정적 품질 게이트 시스템"**
논문. 도메인(산업안전 문서→이주노동자 시험)도 선행에 없는 조합.

## 후보 4. 외국인 노동자 직무 한국어 벤치마크 공개 (2단계 후)

문항 세트 + 루브릭 + 이중 라벨 답안 + 악성 공격 세트 + 인간-인간 일치율.
데이터셋 논문은 신규성 부담이 가장 낮고, 이 도메인은 공백. 2단계 라벨링이 완성 조건.
주의: AI Hub 원자료는 재배포 금지라 벤치마크에 포함 불가 — 자체 제작분만.

## 일치율 연구 통계 설계 (계단 5·6 = 후보 4의 뼈대) — 8/2 초안

**무엇을 재나**: 기계-인간 일치율 vs 인간-인간 일치율. 등급(A~E, 순서형)은
**이차 가중 카파(QWK)**, 점수(0~100)는 피어슨 상관을 보조로. 라벨러가 3명 이상이라
쌍이 여럿이면 Krippendorff's α(순서형)를 함께 보고하면 방어가 두터워진다.

**라벨링 프로토콜 (2단계, 팀 6인 중 3인 가정)**
1. 답안 수: 최소 **100건**(쓰기 50 + 말하기 50) — QWK 신뢰구간이 ±0.1 안쪽으로
   들어오는 현실적 최소선. 여유가 되면 150.
2. 각 답안을 **2명이 독립 라벨** + 불일치는 3번째가 조정(조정 전 값으로
   인간-인간 일치율 계산 — 조정 후 값으로 재면 일치율이 부풀려진다).
3. 라벨링 전 **훈련 세션**: 앵커 답안 5개(A~E 하나씩)로 눈높이 맞추기.
   앵커 없이 시작하면 인간-인간 일치율이 낮게 나와 우리 목표(기계≥인간)가
   싱겁게 달성돼 버린다 — 정직한 비교를 위해 인간 쪽을 최상 조건으로.
4. 통계: 부트스트랩(1,000회 재표집)으로 QWK 95% 신뢰구간, "기계-인간 ≥ 인간-인간"
   주장은 쌍대 부트스트랩 차이의 신뢰구간이 0을 포함하는지로 판정.
5. 주의: AI Hub 사람 점수는 발음 평가 중심이라 우리 내용·언어 채점과 구인이
   다르다 — 보조 증거로만 쓰고 본 검증은 자체 라벨로.

## 2차 후보 (8/2 발굴 — 1차 후보·기존 제안과 겹치지 않는 새 각도)

**⑤ 메타모픽 채점 검사**: 뜻 보존 변형(동의어·어순)→점수 불변(INV),
요소 제거·오류 주입→해당 영역만 하락(DIR, 영역 간 오염 검사)을 자동 생성해
상시 회귀 스위트로. CheckList(ACL 2020) 계보이나 채점기 적용 선례 검색에서
못 찾음. 지금 자산으로 즉시 가능 — 공격 세트·변별력 검증의 체계화판.

**⑥ 전사 불확실성 전파**: 전사 K개 → 점수 분포 → 등급 경계에 걸치면
재녹음/인간검토 플래그. LLM 판정 신뢰도(기존 제안)와 별개로 **STT 단계의
불확실성을 점수까지 전파**하는 것. Azure 전환 후에도 유효. 말하기 전용.

**⑦ 모어(L1)별 공정성 감사(DIF)**: AI Hub 모어 메타데이터로 같은 실력대의
국적별 점수 편차 측정. 우리 고유 질문: 전사 보정의 국적 힌트가 오히려 편향을
만드는가. 2단계 데이터 필요. 고부담 시험 공정성 요건 — 심사·논문 양쪽 무게.

**⑧ 모의 응시자 IRT 사전 캘리브레이션**: 실력 A~E 페르소나 답안으로 문항
난이도·변별도 사전 추정 → 실데이터 검증. 교과서 방법의 적용 기여로만 주장.

우선순위: ⑤(본선 전 가능) → ⑦(2단계) → ⑥(Azure 후) → ⑧(여유).

## 3차 후보 (8/2 발굴 — LoRA 로 상용 STT 를 "우리 니치에서" 이기는 설계)

전제: 범용 CER 로 상용(Gemini/Azure)을 이기려 하면 진다. 이길 곳은 상용이
구조적으로 못 하는 것 — 우리가 실측으로 잡은 약점에서 시작한다.

**⑨ 오류 보존 특화 LoRA STT (본진)**: 상용 STT 는 표준형으로 정규화하도록
학습돼 있고 우리는 그걸 못 바꾼다(실측: few-shot 지시로도 "안 돼습니다" 교정을
못 막음). AI Hub 교육용 세트의 **오류 보존 사람 전사**로 HF Whisper(small/medium)를
LoRA 학습해 "들린 그대로" 전사로 목표를 바꾼다. 평가 지표를 신설: **오류 보존율**
(라벨된 학습자 오류 중 전사에 살아남은 비율) + CER 병행, 기본 Whisper vs 우리
LoRA vs Gemini 3자 비교. 후보 ①(세탁 편향 측정)과 2부작 계단: ①측정→⑨교정.
Colab 무료 GPU 로 가능. 착수 조건은 PLAN 의 기존 LoRA 항목과 동일.

**⑨의 구인 경계 (8/2 보강 — 팀 논의에서 나온 급소)**: 훈련 목표는 "발음 그대로"가
아니다 — 표준 발음 때문에 옳은 발화도 표기와 달라진다("여덟 시"의 표준 발음이
[여덜씨]라, 소리대로 적으면 옳게 말한 사람에게 가짜 오류를 제조한다). 목표는
**"표준 철자로 적되, 소리로 구별되는 오류만 보존"**: 조사·어미·어휘 오류(다르게
들림)는 보존하고, 소리가 같은 표기 차이(여덟/여덜, 돼/됐)는 표준 철자로 수렴 +
**말하기에서 측정 불가 오류 클래스로 선언**(오류 보존율 지표의 분모에서도 제외).
AI Hub 교육용 데이터의 2층 전사(표준 철자 + 발음 + 오류 태깅)가 이 목표의 학습
정답지를 만들 수 있게 해 준다. 채점기 쪽은 이미 말하기에서 맞춤법 자질을 끄고
있어(errors.py WRITING_ONLY_ERROR_TYPES) 절반은 방어돼 있음을 코드로 확인.

**⑨-보완 (8/2): 이원 전사 + diff 오류 후보**. 교체가 아니라 병행 — 정규화
전사(상용)는 내용 채점에, 보존 전사(LoRA)는 언어 채점에 쓰고, **두 전사의
차이(diff) 구간을 오류 후보로** LLM 판정에 넘긴다(상용의 '오류 지우개'가 공짜
오류 표시기로 반전). LoRA 가 상용을 못 이겨도 시스템이 성립하는 구조.
선행 단계: ① 기본 Whisper(학습 전)의 보존 성향 파일럿 — CPU 로 오늘 가능,
기본부터 보존이 좋으면 diff 는 즉시 작동 ② SttPort 그림자 모드로 위험 제로
병행 운용(⑩ 드리프트 감사와 인프라 공유) ③ AI Hub 후 LoRA 로 보존 강화.

**⑨-선행 (8/2 입수): HUFS 한국어 L2 MDD 논문 (Appl. Sci. 2026, 16, 2426).**
Whisper-medium 을 우리와 같은 AI Hub L2 세트로 파인튜닝해 "소리 나는 그대로"
전사(발음 전사)를 만들고 발음 오류 진단(MDD)까지 감 — PER 9.03%→4.87%.
시사점 4개: ① 방향이 우리 ⑨와 반대(발음 전사 vs 표준철자+가청 오류)라
**delivery(발음) 영역의 Azure 백업 경로**가 된다 ② 오염 녹음을 RMS 필터로
거른다 — 우리 무음 관문과 같은 계열(문헌 지지) ③ AI Hub 데이터 함정 실태:
옆 응시자 목소리 혼입, 라벨 불균형(사과 5,727중복), 낭독 40초 폭주 —
전처리 레시피(SNR 10dB·RMS 0.01·15초 컷)를 우리 CER·세탁 측정에 차용
④ 통째 재현은 GPU·수작업 평가셋(전문가 2인 2,000문장) 때문에 해커톤 규모가
아님 — 축소판(whisper-small+LoRA)만 ⑨ 착수 조건 하에서 고려.

**⑨-우위 전략 (8/2)**: PER 정면승부는 하지 않는다(저쪽 홈그라운드). 이기는 링 3개 —
(1) **하류 평가로 지표 전환**: "전사가 정확한가(PER)"가 아니라 "그 전사로 채점하면
사람 점수와 더 일치하는가(QWK)". 채점 파이프라인이 있는 우리만 잴 수 있고 계단 6과
직결. (2) **L1별 LoRA 어댑터**: 논문이 '향후 과제'로 남긴 모어별 대응 — 전체
파인튜닝은 모델 1개지만 LoRA 는 국적별 어댑터가 가능(학습 1회 3~10 GPU시간,
4090 대여 시 6~7천원). (3) **정제 레시피 상속**: 논문의 전처리 기준을 출발선으로
받고 무음 관문·TTS 가청 오류 증강을 추가. GPU 예산: 실험 5~6회 반복해도 총 1~2만원
(Colab 무료/Kaggle 로는 0원 가능).

**주장 규칙 (8/2 확정)**: "저 논문보다 성능 좋다"는 금지 — 저쪽 4.87%는 비공개
평가셋 숫자라 비교 자체가 성립 안 하고, 아는 심사위원 앞에서 무너진다. 올바른 주장:
"저 논문은 받아쓰기(PER)까지 쟀고, 그것이 채점 정확도로 이어지는지는 아무도 안 쟀다 —
우리가 그 지표(하류 QWK)를 정의하고 첫 숫자를 만들었다." 겹치는 비교가 필요하면
**기본 Whisper 를 공통 상대로 한 개선 폭**만 나란히 놓는다(정직한 비교).

**⑩ 상용 API 드리프트 감사**: 상용 API 는 예고 없이 모델이 갱신돼 같은 음성이
시점에 따라 다르게 전사될 수 있다 — 시험의 시점 간 재현성 문제(재시험·이의제기).
고정 음성 세트를 주기적으로 태워 전사 변화를 기록, 버전 박제 가능한 로컬 모델과
대조. **비용 제로, 오늘부터 스냅샷 축적 가능.** 로컬 모델의 두 번째 구조적 우위.

**⑪ 무음·비발화 명시 학습**: 무음→빈 출력 쌍을 학습에 섞어 환각을 모델 수준에서
억제. 유사 선행(Calm-Whisper) 있어 "적용"으로만 주장. RMS 관문·스키마 검증과 합쳐
3층 방어 스택으로 후보 ②의 방어 편에 편입.

공통 전제(정직): AI Hub 데이터 필요, 낭독체 위주라 자유 발화 일반화 별도 검증,
학습·평가 이틀 소요 → 2단계 본진(일치율) 궤도 확인 후 착수. ⑩만 즉시 시작 가능.

## 4차 후보 (8/3 발굴 — "공개 시험지 + 공개된 상대 숫자"가 있는 링)

비공개 평가셋과의 비교 금지 규칙을 지키면서 "논문/공식 수치보다 좋다"를 성립시키는 길:

**⑫ AI Hub 에세이 글 평가 데이터 (dataSetSn=545) 벤치마크 도전**: 사람 채점
11개 세부 지표가 달린 공개 데이터 + **공식 베이스라인(BERT+GRU) 수치 공개**.
우리 3층(자질+XGBoost 결합)으로 같은 분할에서 상회하면 "공개 벤치마크에서 공개
숫자를 이겼다"가 처음 성립. 보너스: 사람 라벨 수만 건으로 **XGBoost 결합층을 자체
라벨링 전에 실전 리허설**(계단 5 예행). GPT-4 직접 채점 QWK 0.68 참조점도 있어
"생 LLM 대비" 서사 연장. 주의: 도메인이 학생 에세이라 주장은 "방법론이 공개 벤치에서
통한다"까지 — 니치 성능은 계단 6이 담당. AI Hub 신청 목록에 545 추가 필요.
착수 전 데이터 카드의 베이스라인 수치·평가 분할 동일 조건 확인 필수.

**⑬ 국립국어원 AI 언어 능력 평가(2022, 종료 대회) 과제**: 공개 과제 데이터 +
F1 채점 방식 + 참가팀 성적 공개 — 우리 2층 오류 탐지를 태워 공인된 자리에서
F1 을 만든다. 여유 시 과제(2단계 후반).
