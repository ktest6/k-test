## 기술 스택 통합 계획 (8/3 확정) — STT · 채점 · XGBoost 3층

```
음성 ─[1층 STT: 오류 보존 LoRA]→ 전사 ─[2층: 구조 분리 채점]→ 자질 ─[3층: XGBoost 결합]→ 점수
```

층마다 이기는 상대와 지표를 고정한다 (비공개 평가셋과의 비교 금지 — RESEARCH.md 주장 규칙):
- 1층: 기본 Whisper·Gemini 상대, 오류 보존율·CER (AI Hub 정답 전사로)
- 2층: 생 LLM 직접 채점 상대 — **완승 실측 완료** (계단 4)
- 3층: 손 가중치 상대, 사람 라벨 QWK 개선 (계단 5)
- 끝판: 음성→최종점수 하류 QWK ≥ 인간-인간 (계단 6) — "받아쓰기가 채점 정확도로
  이어지는지는 아무도 안 쟀다. 우리가 그 지표를 정의하고 전 층에서 베이스라인을 이겼다"

**병목은 라벨.** XGBoost 는 라벨 없이 못 배우므로 라벨링 킷(앵커 5 + 시트 + 지침)을
1단계(8/5~6)로 앞당기고, 8/7~9 에 파일럿 20건으로 프로토콜을 검증한 뒤 2단계에서 100건.

### 기함 선언 (8/3) — "채점을 위한 받아쓰기"

임팩트·논문 요건을 모두 만족하는 단일 기함. 주장 한 줄: **"상용 STT 는 응시자의
실수를 지워 말하기 채점을 오염시킨다. 우리는 실수를 보존하는 모델을 학습했고,
받아쓰기 정확도가 아니라 채점 정확도(사람 점수와의 QWK)로 증명했다."**

구성 4개 (상세·선행 대조는 RESEARCH.md ⑨·⑨-보완·주장 규칙 절):
1. 새 지표 — 오류 보존율 / 2. 새 장치 — 이원 전사 diff(상용의 교정 자리 = 오류 후보)
3. 우리 모델 — Whisper LoRA (+모어별 어댑터) / 4. 새 평가 — 하류 QWK (기존 논문 미측정)
안전장치: LoRA 가 실패해도 "상용 STT 세탁 편향 정량화"만으로 논문 반쪽 성립.
XGBoost(계단 5·6)는 예정대로 가되 논문 주인공은 기함이다. 증류(LLM→소형 모델)는
비전 슬라이드 + 2호 논문 후보로 보류.

### 세탁 탐지기 (8/6 채택) — 기함의 킥: 데이터가 스스로 깨끗해지는 루프

배경: 사람 라벨 신뢰율 72%(재완 100건) → 팀 4명 399건에서도 교정율 34.1%로 교차 확인.
이 오염이 v1 상한을 누르는지 확인하며, "데이터를 쓰는 팀"에서 "데이터를 고치는 팀"으로 격을 올린다.

계단 5개: ①발견(사람 귀 감사, 완료) → ②탐지기(독립 STT 증인단 다수결로 학습쌍 1만 개
전수 검사 — 모델들이 오류 형태로 일치하는데 라벨만 표준형이면 세탁 의심) → ③검증(탐지기
정밀도를 gold 499 로 채점 — 어느 라벨이 세탁인지 사람이 이미 아는 시험지) → ④정제(의심
쌍만 제외, 고쳐 쓰지 않음) → ⑤증명(정제 데이터로 v2 학습, v1 과 3지표+하류 비교).

증인단 규칙: 세탁하는 모델 배제(Gemini 탈락 — 실측 세탁 최다), 답안지를 본 모델
배제(v0·v1 탈락 — 그 라벨로 학습해 순환 오염). 후보 6종(Whisper small·large-v3,
Qwen3-ASR-1.7B, SenseVoice-Small, OWSM v4, Cohere Transcribe(라이선스 확인 필요))을
gold 100 오디션(CER·보존율·오탐)으로 3~4종 채용 — 문맥형 2 + 직청형(CTC) 최소 1.
gold 는 오디션용/최종 증명용으로 분리해 시험지 소모를 막는다.

주장 범위(8/6 선행 조사): 다수결 필터 자체는 표준 기법이라 발명 주장 금지. 우리 몫은
**거르는 방향의 반전**(기존 필터는 오류 보존 라벨을 버린다 — 우리는 세탁 라벨만 버린다),
세탁률 실측(28~34%), 탐지기의 gold 검증, 하류 연결 — "조사 범위에서 선행 미발견"까지만.

### LoRA 데이터 보강 4갈래 (8/19 설계 — 상세는 `DESIGN_lora_data.md`, 팀 합의 전)

v1 실패(병목 = 학습 목표·라벨)와 데이터 부족을 함께 푸는 우선순위: **A 공짜 실험**(지문 프롬프트 주입 + 71479 원본의 발음전사·평가점수 파트 인벤토리) → **B 실데이터 확장**(같은 시리즈 AI Hub 3종 3,575시간 자동승인 — 발음전사(오류 보존)와 1~5점 평가라벨 포함, 평가라벨은 계단 5 XGBoost 라벨로 직행) → **C 목표·라벨 교정**(verbatim 태그로 세탁 의심 11% 복권, 증인 앙상블을 재라벨 공장으로 반전 — 골든셋 게이트 필수, 토큰 가중 CE, 여력 시 DPO) → **D 합성**(오류 주입 텍스트→TTS, 스모크 30문장 80% 게이트 통과 시에만, 혼합 10~30% 상한). 조사 에이전트 14개로 출처 전수 검증(허위 인용 0).
