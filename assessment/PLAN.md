## 전체 그림

```
[관리자] 안전문서 업로드 → AI가 문항+체크리스트 초안 생성(인용 검증) → 관리자 승인
                                                                    ↓
[응시자] 맞춤 시험 응시 → 기존 채점 파이프라인 (무변경) → 점수·등급·근거
```

- 쓰기: 문서 텍스트에서 생성 / 말하기: 문서 속 이미지 **파싱**(생성 금지) 기반 — 후순위
