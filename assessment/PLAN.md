# K-TEST 실행 계획 v2 (~8/10)

> 2026-07-31 재편. 방향 전환(안전문서 기반 맞춤 시험, `IDEA.md`)을 반영.
> **원칙: 기존 자산은 전부 재사용된다.** 채점 파이프라인·문항 형식·배포는 새 방향에서도 그대로 쓰인다.
> 갈아엎는 게 아니라 "문서→문항 생성"이라는 입구를 앞에 붙이는 것이다.

## 방향 전환 요약 (팀 합의 전 — 🔶 표시는 합의 후 확정)

```
[관리자] 안전문서 업로드 → AI가 문항+체크리스트 초안 생성(인용 검증) → 관리자 승인
                                                                      ↓
[응시자] 맞춤 시험 응시 → 기존 채점 파이프라인 (무변경) → 점수·등급·근거
```

- 쓰기: 문서 텍스트에서 생성. 말하기: 문서 속 이미지(파싱)로 사진설명형 — 생성 이미지는 금지
- 양보 불가 원칙: ① 응시자별 실시간 생성 금지(시험 전 생성 + 승인) ② 모든 생성물에 문서 인용 근거
