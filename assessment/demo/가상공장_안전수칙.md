# (주)케이테스트 식품공장 안전수칙

> 시연용 가상 문서. 실제 KOSHA 안전보건 지침의 통상 내용을 바탕으로 자작했으며,
> 특정 기업·제품과 무관하다. 시연에서 이 문서를 업로드하면 문항 생성 → 승인 →
> 응시 → 채점의 전체 흐름을 보여줄 수 있다.

## 1. 공통 수칙

1. 작업장에 들어가기 전에 반드시 안전모와 미끄럼 방지 안전화를 착용한다.
2. 작업 중 이상한 소리, 냄새, 진동을 느끼면 즉시 작업을 멈추고 반장에게 보고한다.
3. 바닥에 물이나 기름이 떨어져 있으면 밟지 말고 먼저 노란색 경고 표지판을 세운다.
4. 사고가 나면 크든 작든 반드시 당일에 관리자에게 알린다. 숨기면 더 큰 사고가 된다.

## 2. 포장 라인 (컨베이어)

1. 컨베이어가 움직이는 동안에는 절대 벨트 위로 손을 넣지 않는다.
2. 벨트에 물건이 끼었을 때는 반드시 빨간색 비상 정지 버튼을 먼저 누르고 꺼낸다.
3. 비상 정지 버튼은 각 라인의 시작과 끝, 두 곳에 있다.
4. 장갑이 벨트에 말려 들어갈 수 있으므로 헐렁한 장갑은 착용하지 않는다.

## 3. 지게차 구역 (자재 창고)

1. 지게차가 다니는 통로(바닥의 노란색 선 안쪽)로는 걸어 다니지 않는다.
2. 지게차 뒤쪽은 운전자가 보지 못한다. 지게차 뒤로 지나가지 않는다.
3. 지게차에 화물을 실을 때는 무거운 것을 아래에, 가벼운 것을 위에 쌓는다.
4. 화물을 2단 이상 쌓을 때는 반드시 고정 끈으로 묶는다.

## 4. 세척실 (화학물질)

1. 세척제를 사용할 때는 반드시 고무장갑과 보안경을 착용한다.
2. 세척제가 피부에 닿으면 즉시 흐르는 물로 15분 이상 씻고 관리자에게 알린다.
3. 서로 다른 세척제를 섞지 않는다. 섞으면 유독 가스가 생길 수 있다.
4. 세척제 통은 사용 후 반드시 뚜껑을 닫고 지정된 보관함에 넣는다.

## 5. 냉동창고

1. 냉동창고에 들어갈 때는 반드시 방한복을 입고, 문 옆의 재실 표시등을 켠다.
2. 냉동창고 안에서는 혼자 30분 이상 작업하지 않는다.
3. 문이 얼어서 안 열리면 당황하지 말고 문 안쪽의 비상 버튼을 누른다.

## 6. 비상 상황

1. 화재가 나면 "불이야"라고 크게 외치고, 가까운 비상구로 대피한다.
2. 비상구는 포장 라인 동쪽 끝과 자재 창고 서쪽 입구, 두 곳이다.
3. 대피할 때는 엘리베이터를 타지 않고 계단을 이용한다.
4. 대피 후에는 주차장 집합 장소에 모여 반장에게 인원 보고를 한다.
