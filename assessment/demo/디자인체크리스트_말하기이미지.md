# 말하기 문항 이미지 제작 체크리스트 (디자이너 전달용)

> ※ 2026-08-30: 말하기 문항이 실제 사진 4장(SPK-101~104, `speaking_v1.json`)으로 바뀌었다.
> 그래서 이 그림 지시서는 옛 문항(v0, SPK-001~005) 기준이라 지금 문항과 맞지 않는다.
> 참고용으로만 남긴다.

> 받는 사람: 양은희 (디자인)
> 목적: 말하기 문항 5개는 지금 글(텍스트)로만 상황을 설명한다. 응시자가 한국어를
> 시험 보는 사람이라 **글을 읽는 부담을 줄이고, 그림을 보고 말하게** 하려고 한다.
> 이 문서는 "그림에 꼭 들어가야 할 것 / 절대 넣으면 안 되는 것"을 문항별로 정리한 것이다.
>
> 배경 설정: 시연용 가상 회사 **(주)케이테스트 식품공장** (`가상공장_안전수칙.md` 참고).
> 다섯 장 모두 같은 공장 안 장면으로 그리면 시연 때 하나의 이야기처럼 보인다.

---

## 왜 체크리스트가 필요한가 (원리 2줄)

- 그림에 **한국어 글자가 있으면** 응시자가 그걸 읽고 말한다 → 말하기 시험이 아니라 읽기 시험이 된다. **글자 금지.**
- 그림에 **채점 요소가 빠지면** 응시자가 말할 재료가 없는데 채점표는 감점한다 → 불공정. **필수 요소 전부 포함.**

그래서 모든 그림의 합격 기준은 하나다: **"글자 없이, 그림만 보고 채점 항목을 전부 말할 수 있는가."**

---

## 공통 규칙 (5장 전부 적용)

| # | 규칙 | 이유 |
|---|---|---|
| 1 | 그림 안에 **한국어 단어·문장 금지** | 정답 유출 방지 (말하기가 읽기가 됨) |
| 2 | 숫자·기호는 **문항에 꼭 필요한 것만** 허용 (아래 문항별 표에 명시) | 창고 번호·시각 등은 그림으로 전달할 방법이 숫자뿐 |
| 3 | **반장(상급자)은 5장 모두 같은 표식**으로 통일 — 예: 주황 조끼 + 완장, 동료는 파란 작업복 | 응시자가 "누구에게 말하는지"를 보고 높임말을 고르게 됨 (채점 항목) |
| 4 | 말풍선을 넣으려면 **빈 말풍선 또는 "?"만** | 규칙 1과 동일 |
| 5 | 한 장에 핵심 요소 **5개 이내**, 선 굵게 | 시험 화면에서 작게 보여도 알아봐야 함 |
| 6 | 인물의 인종·성별이 특정되지 않는 중립적 그림체 | 응시자가 다양한 국적의 외국인 노동자 |
| 7 | 사고가 **이미 난 장면 금지** (피, 부상, 추락 중) — 항상 "위험한 상황" 또는 "일상 업무" 단계까지만 | 시험 불안 유발 방지 + 문항 의도(예방·보고)와 일치 |
| 8 | 포맷: 가로 16:9, PNG, 배경 흰색 계열 | 시험 화면(프론트) 삽입 기준 |

## 문항별 체크리스트

### 그림 1 — SPK-001 고장 보고 (포장 라인 컨베이어)

응시자가 할 말: "기계가 멈췄어요 → 버튼을 눌러 봤는데 안 돼요 → 어떻게 할까요?"

| 구분 | 내용 |
|---|---|
| ✅ 꼭 들어갈 것 | ① 멈춘 컨베이어 벨트 (빨간 경고등 켜짐, 벨트 위 물건이 멈춰 쌓임) |
| | ② 응시자(주인공)가 **빨간 비상 버튼을 눌러 봤지만 소용없는 모습** (버튼 위 손 + ❌ 표시) |
| | ③ 조금 떨어진 곳에 **반장** (주황 조끼, 이쪽을 아직 못 봄) |
| ⛔ 금지 | 연기·불꽃 (화재로 오해), 한글 라벨 |
| 🔢 허용 숫자 | 없음 |
| 🔍 완성 검수 질문 | 그림만 보고 "무엇이 고장났는지 / 뭘 해 봤는지 / 누구에게 보고하는지" 3가지가 다 나오는가? |

### 그림 2 — SPK-002 위험 경고 (안전모 미착용)

응시자가 할 말: "안전모를 안 쓰셨어요 → 떨어지면 다쳐요 → 쓰고 하세요."

| 구분 | 내용 |
|---|---|
| ✅ 꼭 들어갈 것 | ① **동료**가 사다리 위 높은 곳에서 작업 중, **머리에 아무것도 없음** |
| | ② 안전모가 **사다리 아래 바닥에 놓여 있음** (안 쓴 게 한눈에 보이게) |
| | ③ 높이가 느껴지는 구도 (아래에서 올려다보는 응시자 시점 인물 1명) |
| ⛔ 금지 | 떨어지는 중이거나 다친 모습 (공통 규칙 7), 반장 표식 (이 문항의 상대는 **동료**) |
| 🔢 허용 숫자 | 없음 |
| 🔍 완성 검수 질문 | "뭐가 위험한지(안전모 없음+높은 곳) / 왜(떨어짐) / 뭘 하라고(써라)"가 그림에서 나오는가? |

### 그림 3 — SPK-003 지시 다시 말하기 (자재 창고)

응시자가 할 말: 반장의 지시("2시에 2번 창고, 파란 상자를 1층으로, 끝나면 전화")를 자기 말로 반복.

⚠️ 이 문항만 특수: 지시 자체는 **음성으로 들려준다.** 그림은 들은 내용을 기억하게 돕는 보조 화면이다.

| 구분 | 내용 |
|---|---|
| ✅ 꼭 들어갈 것 | ① **반장**이 응시자에게 말하는 장면 + 말풍선 |
| | ② 말풍선 **안은 그림 4개(픽토그램)로만**: 시계(2시) / 문에 숫자 2가 붙은 창고 / 파란색 상자 더미 / 전화기 |
| | ③ 상자 옆에 **아래층 방향 화살표 + 숫자 1** (1층으로 옮김) |
| ⛔ 금지 | 말풍선 안 한글 (지시문이 글로 보이면 듣기 평가가 무너짐) |
| 🔢 허용 숫자 | **2** (창고 번호), **1** (층), 시계 바늘 2시 |
| 🔍 완성 검수 질문 | 지시를 못 들은 사람이 그림만 봐도 "언제/어디/무엇을/끝나면" 4가지를 짚을 수 있는가? |

### 그림 4 — SPK-004 완료 보고 (포장 작업)

응시자가 할 말: "포장 끝냈어요 → 20개 했어요 → 하나가 찌그러져 있었어요."

| 구분 | 내용 |
|---|---|
| ✅ 꼭 들어갈 것 | ① 포장이 끝난 **상자 더미를 셀 수 있게 정렬** (4×5 = 20개 권장 — 세는 게 과제이므로 겹쳐 가리지 말 것) |
| | ② 그중 **1개만 찌그러진 상자** (특이사항 말할 재료) |
| | ③ 보고받는 **반장** (주황 조끼) + 뿌듯한 표정의 응시자 |
| ⛔ 금지 | 상자 위 한글 상표, 수량을 알려주는 숫자 표기 (세어서 말하는 게 과제) |
| 🔢 허용 숫자 | 없음 (개수는 그림으로 세게 함) |
| 🔍 완성 검수 질문 | 그림에서 상자를 실제로 세면 정확히 20개인가? 찌그러진 상자가 한눈에 보이는가? |

### 그림 5 — SPK-005 도움 요청 (무거운 자재)

응시자가 할 말: "이거 옮겨야 하는데 → 혼자는 너무 무거워요 → 좀 도와주시겠어요?"

| 구분 | 내용 |
|---|---|
| ✅ 꼭 들어갈 것 | ① 응시자가 **큰 자재(포대 또는 대형 상자)를 혼자 들다 기우뚱**하는 모습 (땀방울, 기울어진 자세) |
| | ② 옮겨야 할 **목적지가 보이게** (예: 손수레 또는 선반이 옆에) |
| | ③ 근처에 **동료 1명** (파란 작업복, 다른 일 하는 중) |
| ⛔ 금지 | 반장 표식 (상대는 동료), 이미 깔리거나 다치는 장면 |
| 🔢 허용 숫자 | 없음 |
| 🔍 완성 검수 질문 | "무슨 일인지(옮기기) / 왜 도움이 필요한지(무거움) / 누구에게 부탁하는지"가 그림에서 나오는가? |

## 납품 전 최종 점검 (5장 공통, 디자이너 셀프 체크)

- [ ] 그림 안에 한국어 글자가 한 글자도 없다 (허용된 숫자 제외)
- [ ] 각 그림의 "완성 검수 질문"에 그림만 보고 답할 수 있다
- [ ] 반장은 5장에서 같은 복장(주황 조끼)이고, 동료 문항(그림 2·5)에는 반장이 없다
- [ ] 다치거나 사고가 난 장면이 없다
- [ ] 휴대폰 크기로 축소해도 핵심 요소가 보인다
- [ ] 가로 16:9 PNG

완성본은 문항+채점 파트(전재완)에게 전달 → 우리가 검수 질문으로 확인 후 문항 JSON에 이미지 경로를 연결한다.
