# 시연 대본 (본선용, 이중 대비)

> 원칙: 말은 짧게, 화면과 숫자가 일하게 한다. 각 장면에 "말할 문장"과 "보여줄 것"을
> 분리했다. 관리자 화면(프론트)이 늦어질 경우를 대비해 모든 장면에 **B안(화면 없이
> 보여주는 법)**을 붙였다.

## 준비물 체크리스트 (시연 30분 전)

- [ ] 채점 서버 살아 있음 (`/health` 응답 확인) — 죽어 있으면 `서버시작.bat`
- [ ] `demo/가상공장_안전수칙.md` 파일
- [ ] 시연용 녹음 2개: ① 정상 답변 wav ② 무음 wav (마이크 끄고 5초 녹음)
- [ ] 백업: 모든 장면의 결과 스크린샷 (인터넷이 죽어도 발표 가능하게)

---

## 장면 1 — 문서가 시험이 된다 (1분)

**말**: "관리자가 하는 일은 하나입니다. 자기 공장의 안전수칙을 올리는 것."

**보여줄 것 (A안)**: 관리자 화면에서 `가상공장_안전수칙.md` 업로드 → 문항 초안 생성
→ 승인 버튼.
**B안**: 터미널에서 `POST /generate-items` 호출 → 응답 JSON의 문항·체크리스트·
**문서 인용 근거**를 보여준다.

**꼭 말할 숫자**: "인용 근거가 없는 문항은 자동 폐기됩니다 — 규칙 도입 전 폐기율
100%였던 것이 지금 0%입니다. 그리고 응시자마다 문제를 새로 만들지 않습니다.
관리자가 승인한 같은 문제로 모두가 시험을 봅니다 — 시험이니까요."

## 장면 2 — 말하고, 채점받는다 (1분 30초)

**말**: "이제 응시자입니다. 베트남에서 온 노동자가 기계 고장을 보고한다고 해 보겠습니다."

**보여줄 것**: 마이크로 직접 말하기 (SPK-001: "반장님, 포장기가 갑자기 멈췄습니다.
전원을 다시 눌러 봤는데 안 됩니다. 어떻게 할까요?") → 점수 화면: 종합 점수 +
영역별 점수 + **근거 인용** ("'전원을 다시 눌러 봤는데' — 시도한 조치를 말함 O").
**B안**: 미리 준비한 녹음 ①을 `/score`로 호출, 응답 JSON을 크게 띄운다.

**꼭 말할 숫자**: "같은 답안을 몇 번 채점해도 점수가 완전히 같습니다 — 재현성 100%.
점수는 AI가 찍는 게 아니라 코드가 계산하기 때문입니다. AI는 사실 확인만 합니다."

## 장면 3 — 심사위원을 놀라게 하는 30초 (무음 공격)

**말**: "이 시스템이 왜 필요한지 30초로 보여드리겠습니다. 마이크가 고장 난 응시자를
흉내 내 보겠습니다."

**보여줄 것**: 무음 녹음 ②를 채점 요청 → **503 거절** ("음성에서 소리를 찾지
못했다... 측정값 0.0"). 이어서 슬라이드 한 장: "같은 무음을 생 LLM에게 채점시키면
**95점 A**를 주고, 채점 근거까지 지어냅니다(실측)."

**꼭 말할 숫자**: "AI에게 그냥 맡기면 무음이 95점을 받습니다. 저희는 소리 크기를
물리적으로 재서 거절합니다. 이 차이가 저희가 만든 구조의 가치입니다."

## 장면 4 — 우리가 학습시킨 모델 (기함, 1분)

**말**: "받아쓰기 AI에는 알려지지 않은 결함이 있습니다. 응시자의 문법 실수를 몰래
고쳐 적습니다. 실수 4개 중 1개가 사라집니다 — 저희가 실측했습니다."

**보여줄 것**: 슬라이드 2장 — ① 세탁 사례 표 (사람 정답지 "미국 사는데" vs AI
"미국**에** 사는데") ② before/after 표: 언어 점수 상관 0.47 → (학습 후 숫자).
**학습이 아직이면**: "그래서 실수를 보존하는 모델을 직접 학습 중이고, 성공 기준은
이 0.47이 오르는 것"까지만 — 없는 숫자를 약속하지 않는다.

## 장면 5 — 마무리 (30초)

**말**: "정리하면 — 문서 하나로 시험이 만들어지고, 점수는 재현 가능하고, 부정
답안은 구조가 막고, 받아쓰기의 결함까지 저희가 직접 학습한 모델로 고치고 있습니다.
비용은 응시자 한 명에 약 18원입니다."

## 예상 질문 3개와 답

- **"그냥 GPT한테 채점시키면 되지 않나요?"** → "저희도 실험했습니다. 같은 모델로
  직접 채점시키면 무음에 95점 A를 주고, 3회 점수가 10점씩 흔들립니다. 올해 나온
  논문도 같은 실험에서 QWK 0.24를 보고했습니다. 저희 구조는 0.89입니다."
- **"이미 비슷한 연구 있지 않나요?"** → "네, 셋을 압니다. 한국어 쓰기 채점(2025),
  한국어 발음 진단(2026), 영어권 오류 보존 전사(ACL 2024). 셋 다 '받아쓰기 또는
  채점 한쪽'에서 멈췄고, 저희는 그 둘을 이어 '받아쓰기가 채점 정확도를 바꾼다'를
  처음 측정했습니다."
- **"데이터는요?"** → "AI Hub 공공 데이터로 검증했고, 시험 문항·채점 기준은 전부
  자체 제작입니다. 데이터 라이선스에 따라 원음은 재배포하지 않습니다."
