# RunPod 작업 순서 — 그래픽카드를 빌려 쓰는 세 가지 일

시연용 서버(GCP)와 달리 여기는 **필요할 때만 켜고 끝나면 끄는** 자리다.
켜 두면 돈이 계속 나가므로, 할 일을 정해 놓고 들어가서 끝내고 나온다.

여기서 하는 일은 셋뿐이다.

| | 무엇 | 왜 GPU 가 필요한가 |
|---|---|---|
| ① | 증인 4종 받아쓰기 | 내 PC 로는 26시간 걸린다(8/25 실측). GPU 로 몰면 몇 시간이다 |
| ② | v3 LoRA 학습 | 학습은 그래픽카드 없이는 사실상 못 한다 |
| ③ | 평가(A/B 비교) | 모델 여러 개를 같은 시험지로 돌려야 해서 오래 걸린다 |

---

## 0. 들어가기 전에 (내 PC 에서)

### 꾸러미 만들기

```bash
# 무엇이 담기는지 먼저 본다
python assessment/deploy/runpod/pack_workbench.py --dry-run

# ②③ 학습·평가용 (음성 없이 · 몇 MB)
python assessment/deploy/runpod/pack_workbench.py \
    --out D:/해커톤데이터/workbench.tar.gz

# ① 증인 받아쓰기용 (음성까지 · 1.9GB · 묶는 데 몇 분)
python assessment/deploy/runpod/pack_workbench.py \
    --out D:/해커톤데이터/workbench_audio.tar.gz \
    --audio D:/해커톤데이터/audit2000/wav
```

> **꾸러미 하나에 wav 폴더는 하나다.** 목록의 음성 경로가 전부 그 한 폴더를
> 가리키게 고쳐지기 때문이다. audit2000 음성을 담았으면 서버에서는 audit2000
> 목록(`audit2000.jsonl`·`audit2000_judge.jsonl`)만 쓴다.

v3 학습에 쓸 라벨 파일처럼 저장소에 없는 것은 `--extra` 로 얹는다.
꾸러미 안 `extra/` 밑에 들어간다.

```bash
python assessment/deploy/runpod/pack_workbench.py \
    --out D:/해커톤데이터/workbench.tar.gz \
    --extra D:/해커톤데이터/labels/gold_team2000.jsonl
```

### 팟 고르기

| 할 일 | 권장 카드 | 시간당 대략 | 왜 |
|---|---|---|---|
| ① 증인 받아쓰기 | RTX 4090 24GB | 0.4~0.7 달러 | 모델을 하나씩 올렸다 내리므로 24GB 면 넉넉하다 |
| ② v3 학습 | RTX 4090 24GB | 0.4~0.7 달러 | whisper-small + LoRA 는 24GB 안에 든다 |
| ② v3 학습(크게) | A100 40GB | 1.2~1.8 달러 | 배치를 키우거나 더 큰 베이스로 갈 때만 |
| ③ 평가 | RTX 4090 24GB | 0.4~0.7 달러 | 추론만 한다 |

- 값은 **대략**이다. RunPod 은 시세와 지역에 따라 달라지므로 빌릴 때 화면의 숫자를 본다.
- 디스크(Volume)는 **100GB 이상**으로 잡는다. 모델 캐시가 수십 GB 로 는다.
- 이미지는 torch 가 미리 깔린 공식 PyTorch 템플릿을 고른다(우리는 torch 를 안 깐다).

### 팟에 올리기

```bash
runpodctl send D:/해커톤데이터/workbench_audio.tar.gz
runpodctl send C:/해커톤/assessment/deploy/runpod/runpod_setup.sh
```

### 팟에서 차리기

```bash
bash /workspace/runpod_setup.sh --tar /workspace/workbench_audio.tar.gz
# 학습·평가만 할 거면 무거운 것을 건너뛴다
bash /workspace/runpod_setup.sh --tar /workspace/workbench.tar.gz --light
```

마지막에 **cuda 를 쓸 수 있다고 나오는지** 반드시 확인한다. 여기서 false 면
뒤의 작업이 전부 CPU 로 돌아 몇십 배 느려진다.

## ① 증인 4종 받아쓰기

감사자 4명이 고친 교정본이 진짜 맞는지 가리려면, 사람 손을 안 탄 받아쓰기 모델
넷(증인)에게 같은 음성을 들려주고 그 결과와 대 봐야 한다. 그 받아쓰기를 여기서 한다.

```bash
cd /workspace/ktest_workbench/assessment/scripts/speech_lab

python launder_transcribe.py \
    --manifest ../../../data/manifests/audit2000_judge.jsonl \
    --device cuda \
    --hf-cache /workspace/hf_cache \
    --out /workspace/launder_audit2000
```

- `--only` 를 안 주면 증인 4명(qwen3-asr · fw-small · owsm-v4 · sensevoice)을 다 돌린다.
- 671건이다(교정 571 + 대조군 100). 2,000건 전부가 아닌 까닭: **정밀도는 고친 건에서만
  나오기 때문**이다.
- 한 건 받아쓸 때마다 곧바로 파일에 적고, 다시 돌리면 이미 한 건은 건너뛴다.
  중간에 끊겨도 같은 명령을 다시 치면 이어서 한다.
- 나오는 것: `/workspace/launder_audit2000/<증인이름>.jsonl` 4개 + `_meta.json`.

**끝나면 내려받고 끈다:**

```bash
tar -czf /workspace/launder_audit2000.tar.gz -C /workspace launder_audit2000
runpodctl send /workspace/launder_audit2000.tar.gz
runpodctl stop pod $RUNPOD_POD_ID
```

내려받은 뒤 판정과 감사자별 정밀도는 **내 PC 에서** 낸다(GPU 가 필요 없다).
명령은 `speech_lab/사용법.md` ⑧-3 절에 있다.

## ② v3 LoRA 학습

```bash
cd /workspace/ktest_workbench/assessment/scripts/speech_lab

# 먼저 확인만 (몇 분). 여기서 깨지면 진짜 학습은 돈만 태운다
python train_lora.py --data /workspace/ktest_workbench/extra/gold_team2000.jsonl --dry-run

# 진짜 학습 + 끝나면 팟 끄기
python train_lora.py \
    --data /workspace/ktest_workbench/extra/gold_team2000.jsonl \
    --out /workspace/adapters/v3 \
    --epochs 5 --batch 8 \
  && tar -czf /workspace/v3_adapter.tar.gz -C /workspace/adapters v3 \
  && runpodctl send /workspace/v3_adapter.tar.gz
```

- `&&` 는 '앞이 성공하면 뒤를 하라'는 뜻이다. **실패하면 팟이 살아 있어 로그를 볼 수 있다.**
- **어댑터를 내려받기 전에는 절대 팟을 끄지 마라. 끄면 디스크가 통째로 사라진다.**
- 다 받은 것을 확인한 뒤에 끈다:

```bash
runpodctl stop pod $RUNPOD_POD_ID
```

## ③ 평가 (A/B 비교)

```bash
cd /workspace/ktest_workbench/assessment/scripts/speech_lab

python eval_ab.py \
    --manifest ../../../data/manifests/audit2000_judge.jsonl \
    --model base \
    --model /workspace/adapters/v2 \
    --model /workspace/adapters/v3 \
    --max-n 100 \
  | tee /workspace/eval_v3.txt
```

- `--model` 은 두 개 이상이어야 비교가 된다. `base`(학습 전) · `gemini` · 어댑터 폴더 경로를 쓴다.
- `gemini` 갈래는 열쇠가 필요하다. 팟에는 열쇠를 올리지 않으므로 여기서는 쓰지 않는다.
- **base·v1·v2·v3 는 반드시 같은 시험지(같은 manifest·같은 --max-n)로 비교한다.**
  시험지가 다르면 숫자를 나란히 놓을 수 없다(`PLAN.md` 8/20 평가 기준).

**끝나면:**

```bash
runpodctl send /workspace/eval_v3.txt
runpodctl stop pod $RUNPOD_POD_ID
```

## 끄는 것을 잊지 않기

```bash
runpodctl stop pod $RUNPOD_POD_ID
```

- `stop` 은 계산을 멈춘다. **디스크(Volume)는 남고 그 값은 계속 나간다.**
  더 쓸 일이 없으면 RunPod 화면에서 팟을 **terminate(삭제)** 한다.
- 삭제하면 `/workspace` 가 사라진다. **결과 파일을 먼저 내려받았는지 다시 확인한다.**
