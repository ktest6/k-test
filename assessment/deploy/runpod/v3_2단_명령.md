# v3 2단(고품질 마무리) 학습 — RunPod 명령 (2026-08-30 정정판)

v2 어댑터 위에 팀 교정본 800건(금+은)을 낮은 학습률로 1에폭 더 가르친다. RTX 4090 24GB 팟 하나, 30분 안팎.

## 0. 팟 만들기 (RunPod 웹)
- Pods → Deploy → GPU **RTX 4090**(24GB) → 템플릿 **RunPod PyTorch 2.x** → Container/Volume Disk 각 **30GB 이상** → Deploy
- 켜지면 **Connect → Start Web Terminal** (검은 화면). 아래 "팟 안" 명령은 여기에 붙인다.

## 1. 파일 보내기 (내 PC에서 send → 팟에서 receive)
꾸러미: `D:\해커톤데이터\workbench_v3.tar.gz` (1.45GB: 음성 2,000 + extra/v3_extra/{목록 2개, adapters/v2})
runpodctl: `D:\해커톤데이터\tools\runpodctl.exe` (2.12.0)

내 PC PowerShell:
```powershell
D:\해커톤데이터\tools\runpodctl.exe send D:\해커톤데이터\workbench_v3.tar.gz
```
→ 화면에 `runpodctl receive 1234-word-word-word` 한 줄이 뜬다. 그 줄을 **팟 터미널에 붙여 넣으면** 받기 시작한다.
같은 방법으로 하나 더:
```powershell
D:\해커톤데이터\tools\runpodctl.exe send C:\해커톤\assessment\deploy\runpod\runpod_setup.sh
```

## 2. 팟 안 — 설치
```bash
cd /workspace && ls -l            # workbench_v3.tar.gz, runpod_setup.sh 둘 다 보여야 함
bash /workspace/runpod_setup.sh --tar /workspace/workbench_v3.tar.gz --light
```
끝에 **`cuda 사용 가능: True`** 가 나와야 한다. (`--light` = 증인 모델 안 깖, 학습에 필요한 것만)

## 3. 팟 안 — 학습 (한 덩어리로 붙이기)
```bash
cd /workspace/ktest_workbench/data
python ../assessment/scripts/speech_lab/train_lora.py \
    --data ../extra/v3_extra/team2000_train_stage2.jsonl \
    --init-adapter ../extra/v3_extra/adapters/v2 \
    --lr 3e-6 --epochs 1 --batch 8 \
    --out /workspace/adapters/v3-stage2 \
  && tar -czf /workspace/v3-stage2.tar.gz -C /workspace/adapters v3-stage2 \
  && echo "=== 학습 끝. 아래 send 코드를 내 PC에서 receive 하세요 ===" \
  && runpodctl send /workspace/v3-stage2.tar.gz
```
- 첫 로그에 **`이어서 배울 어댑터 얹는 중`** 이 보여야 한다. 안 보이면 새 판부터 배우는 것이니 Ctrl+C.
- 음성 경로가 `audit2000/wav/…` 상대경로라 **반드시 `data/` 폴더에서** 실행한다.
- 학습률 3e-6 = v2(1e-5)의 약 1/3. 설계(1/3~1/5) 범위.
- 끝나면 `runpodctl receive <코드>` 줄이 뜬다 → 내 PC PowerShell 에서 `D:\해커톤데이터\tools\runpodctl.exe receive <코드>` (받는 폴더에서 실행: `cd D:\해커톤데이터\adapters` 먼저).

## 4. 팟 끄기 (돈!)
어댑터를 내 PC에 받은 것을 확인한 뒤:
```bash
runpodctl stop pod $RUNPOD_POD_ID
```
그리고 RunPod 웹에서 팟을 **Terminate** 까지 해야 디스크 요금이 안 나간다.
