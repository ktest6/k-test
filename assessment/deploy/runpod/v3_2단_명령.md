# v3 2단(고품질 마무리) 학습 — RunPod 명령 (2026-08-26)

v2 어댑터 위에 팀 교정본 800건(금+은)을 낮은 학습률로 1에폭 더 가르친다. 4090 24GB 팟 하나, 30분 안팎.

## 내 PC
꾸러미: `D:\해커톤데이터\workbench_v3.tar.gz` (음성 2,000 + extra/ 목록 2개 + extra/adapters/v2)

```bash
runpodctl send D:/해커톤데이터/workbench_v3.tar.gz
runpodctl send C:/해커톤/assessment/deploy/runpod/runpod_setup.sh
```

## 팟 안
```bash
bash /workspace/runpod_setup.sh --tar /workspace/workbench_v3.tar.gz
# 끝에 "cuda 사용 가능: True" 확인

cd /workspace/ktest_workbench/data          # 목록의 음성 경로가 여기 기준(audit2000/wav/…)이라 여기서 돈다
python ../assessment/scripts/speech_lab/train_lora.py \
    --data ../extra/team2000_train_stage2.jsonl \
    --init-adapter ../extra/adapters/v2 \
    --lr 3e-6 --epochs 1 --batch 8 \
    --out /workspace/adapters/v3-stage2 \
  && tar -czf /workspace/v3-stage2.tar.gz -C /workspace/adapters v3-stage2 \
  && runpodctl send /workspace/v3-stage2.tar.gz \
  && runpodctl stop pod $RUNPOD_POD_ID
```
- 첫 로그에 `이어서 배울 어댑터 얹는 중` 이 보여야 한다. 안 보이면 새 판부터 배우는 것이니 중단.
- `&&` 라 실패하면 팟이 안 꺼진다 → 로그 보고 직접 `runpodctl stop pod`.
- 학습률 3e-6 = v2(1e-5)의 약 1/3. 설계(1/3~1/5) 범위.
